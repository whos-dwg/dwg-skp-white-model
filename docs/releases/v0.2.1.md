v0.2.1 修正從 GitHub 下載後，`dwg-skp-sync` 因共用核心雜湊不符而無法安裝或啟動的問題。

打包內容統一使用 LF 換行後再計算雜湊，保留逐檔完整性及版本混用檢查。另補上 Git 封存回歸與獨立測試暫存目錄；建模與同步演算法沿用 v0.2.0。

升級時請從[下載與安裝說明](https://github.com/whos-dwg/dwg-skp-white-model/blob/v0.2.1/downloads/README.md)取得同版本的兩個技能，先安裝 `dwg-layered-skp`，再安裝 `dwg-skp-sync`。Python 與原生依賴仍依 README 安裝。

發布候選的完整測試通過 852 項與 127 個子測試，包含 SketchUp 原生測試及合成 DWG 註記 fixture。來源 ZIP 與技能 ZIP 均另行解壓、成對安裝並檢查 `--help`／`doctor`；詳見[驗證紀錄](https://github.com/whos-dwg/dwg-skp-white-model/blob/v0.2.1/docs/VALIDATION.md)。本次未重新操作現場 CAD→SKP UI 同步與 Undo／Redo，維持 Pre-release。
