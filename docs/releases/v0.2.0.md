DWG → SKP White Model 提供建築平面的來源判讀、方案核定、原生 SketchUp 白模建立，以及既有來源白模的 CAD 差異同步。

本次為 `v0.2.0` 公開預覽版，供使用者先行驗證，採用 MIT License。公開來源為乾淨快照，不含客戶圖面、歷史案例、實際模型或工作暫存。

## 使用前注意

- 原生流程需要 Windows、本機 AutoCAD Core Console、相符 .NET SDK 與可載入的 SketchUp C API。整模即時 CAD 讀取目前使用 AutoCAD 2026／.NET 8 SDK。
- Python 需求為 3.11 以上，核心依賴為 Shapely 2.x；PNG 檢視圖可另外安裝 `review` 額外依賴。
- 更新技能時先安裝匹配的 `dwg-layered-skp` 核心，再安裝同版本的 `dwg-skp-sync`。兩者共用 runtime，啟動時檢查發布雜湊。
- 同步需要保留 `DWG_LAYERED_SKP` 來源屬性的既有白模與工作資料，完成後由使用者儲存模型。

## 本版提供

- 唯讀解析 DWG／DXF 或抽取 JSON，保存來源圖層、巢狀圖塊實例、單位及外部參照診斷。
- 以幾何、圖層、圖塊與空間證據辨識牆材、內腔、柱、帷幕、門窗洞／過梁及樓板孔域，產生候選檢查圖。
- 將使用者核定綁定指定預覽版本，依核定計畫生成原生 SKP，重新讀入檢查可編輯群組、Tag、來源屬性與幾何。
- 有真實 CAD 選取時做局部同步；完整空選取時比對整模，只更新支援構件的新增、修改及刪除，保留未變件。
- 在整模模式更新來源綁定的整片 RC 樓板、孔洞、降板，以及受上方板底變更影響的牆、柱與全高帷幕。
- 套用前重讀 CAD／SKP 並核對來源、計畫與幾何漂移；有變更以單筆 Undo 提交，驗證失敗中止交易。無差異不新增 Undo。

## 白模規範與範圍

RC 樓板使用整片、名義等厚的閉合殼並保留核定外框與孔界。缺少其他板厚依據時提出 200 mm 白模預設；牆、柱與全高帷幕按當地實際上方板底收高。樓梯間依來源界線整間含平台挖空，防火門／防火捲簾只保留其 2D 洞口及分區證據。

局部樓板同步、樓梯本體、設備、斜板、斜屋頂與未支援代理物件不在目前通用成模範圍。缺來源、宿主、標高或唯一對應時會列缺項；平面辨識通過不等於已完成構造核定或原生 SKP 交付。

## 快速檢查

本次乾淨快照驗證合計通過 842 個測試與 127 個子測試，包含 28 個 SketchUp 原生合成測試。6 個需專用原生註記 fixture 的測試未執行；實際環境與範圍見[驗證紀錄](https://github.com/whos-dwg/dwg-skp-white-model/blob/v0.2.0/docs/VALIDATION.md)。

下載並解壓來源後，在專案根目錄執行：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe skills/dwg-layered-skp/scripts/dwg_to_skp.py doctor
.\.venv\Scripts\python.exe skills/dwg-skp-sync/scripts/dwg_skp_sync.py doctor
.\.venv\Scripts\python.exe skills/dwg-layered-skp/scripts/dwg_to_skp.py inspect `
  examples/synthetic-plan.json --job work/demo-001
```

合成範例會產生候選預覽，因缺少核定決策而預期回傳 `blocked` 與非零代碼，不產生 SKP。完整建模、同步、測試與授權狀態請參閱倉庫首頁 README。
